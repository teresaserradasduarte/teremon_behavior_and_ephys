## Working style
- Work ITERATIVELY in cell-based (`# %%`) scripts for the VS Code interactive window; small steps the human reviews — not large code dumps.
- Use plan mode before non-trivial work; show evidence (printed numbers, figures), don't assert.
- Data lives OUTSIDE this repo; all paths come from `config.py`. Never write data into the code folder.
- Ask before large refactors, before changing a fixed decision in `MI_PROJECT_CONTEXT.md`, or before deleting files.
